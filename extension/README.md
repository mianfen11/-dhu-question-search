# Chrome 学生手册题库收集扩展 1.3.0

Chrome Manifest V3，要求 **Chrome 120+**。保留正常练习的被动收集器，并增加用户主动开始的自动收集。所有题目保存在 `chrome.storage.local`，不上传；导出兼容 `tools/question_bank.py`。

## 安装或更新

1. 先在旧扩展中暂停计划并导出 JSON 备份，再获取本仓库 `main` 最新代码。已有本地克隆可执行 `git pull --ff-only`。
2. 打开 `chrome://extensions`，开启开发者模式，首次安装选择“加载已解压的扩展程序”，选 **extension 目录**。
3. 已安装时点击原扩展的“重新加载”，确认 **1.3.0**。不要卸载，以免删除本地题库。本版新增 `unlimitedStorage`，用于保存题库分片和旧版备份；如 Chrome 提示权限变更，请确认扩展已重新启用。网站访问权限保持不变。
4. 手动刷新已打开的原站页面，让页面监听代码更新；自行正常登录，不向扩展输入任何凭据。

## 自动收集

本次用户明确说明已经取得平台自动化收集许可，因此启用实际自动访问。授权适用于此收集用途，不等于题目、答案或解析的公开再发布许可。

1. 打开 `https://aidhu.net/web/#/main/handbookAnswer?manual_id=1&chapter_id=1&mode=practice`，或对应实际手册的练习页。选择“使用当前页面手册”可从页面的 manual_id 识别；也可以选择已正常观察到的手册。
2. 设置请求间隔和轮数：默认 **5 秒、1 轮**，间隔仅允许 5～86400 秒，轮数 1～10。后台也校验这些限制。
3. 点击 **开始自动收集**。程序先重新获取该手册章节清单，建立“轮次 × 章节 × 单选/多选/判断”队列，依次串行获取、规范化、合并和保存。无需反复手动进入章节。
4. **保持目标原站标签页打开。弹窗可以关闭，也可以切换到其他标签页。** 同一文档的 Vue SPA 路由切换不影响自动执行；不会自动导航或刷新页面。原站自己操作产生的请求不由自动队列限速，运行期间尽量避免同时手动反复进入练习。
5. 弹窗显示运行状态、当前章节/题型/轮次、任务数、题库总数、各章节题型数量、本轮新增、累计重复、每轮新增、最近请求时间及固定错误原因。
6. 暂停、继续、停止立即更新后台状态；请求正在进行时会尝试 AbortController 取消，不启动后续任务。取消前已经收到的有效题目仍可能保存。若正在结束请求，继续按钮会暂时禁用。停止后不会自动恢复，重新开始是一个新计划。
7. 完成设定轮数自动停止。点击 **导出 JSON** 下载当前题库；运行或暂停时也能导出，不必等计划结束。

请求间隔从**上一次响应处理结束后**计算，不少于设定值。普通运行使用后台 timer；Worker 被 Chrome 回收时，持久化的单次 alarm 唤醒恢复，Chrome 可能延后到约 30 秒或更久，系统休眠也可能延迟；不会为“赶进度”并发或集中补发。

HTTP 或响应体 code 为 **401/403/429** 时立即暂停；网络异常、20 秒请求取消/超时、异常结构、部分题目解析失败、页面客户端不可用也暂停，不自动重试或切换账号/IP/代理。检查正常登录或平台限制后，由用户明确点击继续。错误显示固定原因，不展示原始错误、响应头或认证信息。

有限轮数结束、返回空数组或连续无新增都**不证明题库完整**。每次成功响应只完成一个有限任务；有题目被拒绝的响应保留待处理任务并暂停。没有连续零新增自动终止、无限抽题或隐藏接口探测。

## MV3 执行与恢复

- `auto-runner.js` 使用既有 `queue.js` 建立任务，在 `background.js` 与原有导入/被动收集共用串行存储事务。请求等待在事务之外，不会让暂停/停止等待网络返回。
- 所有任务只绑定一个 `tab_id` 和 Chrome 提供的 `documentId`。第二个标签页不能启动另一个运行/暂停中的队列。只有用户明确继续时，才可绑定当前已登录标签页的新文档。
- 每次请求前持久化请求 ID、任务 ID、目标文档和最近请求时间；响应后的题目与任务完成状态**同次写入**。已完成任务不会重做。
- `auto-page.js` 在原文档 MAIN world 内保留一个请求/回执槽。Worker 休眠或回执后写入失败时，恢复只探测同一个请求 ID，取已有结果，不重新发网络请求。页面同时只运行一个自动请求。
- 原页面被刷新、关闭或浏览器重启后，请求回执可能丢失。若正在执行的请求无法确认，**暂停而非自动重放**，保留未完成任务并提示“页面不可用/回执丢失”；正常打开题库后明确点击继续，可重试该待处理任务。不能承诺在页面和 Worker 同时丢失状态时实现网络请求的严格 exactly-once。
- Chrome 重启后，若尚无请求在执行，后台尝试继续已授权计划；绑定的旧标签页不存在时暂停。浏览器完全关闭时不运行。题目及已完成任务长期保留。
- 写入失败不提前完成任务，也不每30秒无限重试。先保存筛选后的本地回执，再提交题目和任务完成状态；旧页面的回执槽作为补充。未确认请求 ID 保留，存储故障暂停后可点击「恢复待提交回执（不发送新请求）」。恢复成功仍保持暂停/停止，确认进度后再继续。
- 页面/Worker 在本地回执尚未写成功前同时消失，无法凭空恢复该响应。此时保留未确认任务，显示具体的回执丢失/页面不可用原因；「确认重试未确认任务」是显式恢复同一计划的操作，并把旧请求 ID 记入未确认历史，不跳过任务。已停止且存在此类未确认请求时，也可明确确认后恢复原计划。

## 1.3.0 存储与长期运行修复

已确认旧实现每次派发/完成任务都重写 `questionBankV1` 的整个题库；异常处理还会把处理异常、读取异常和写入异常统一显示为 storage_error，并反复探测回执。旧代码已经通过后台 Promise 队列串行处理导入/被动/自动写入，**没有发现绕过该队列的题库竞争写入**。仅凭用户旧版提示不能确认真实浏览器是配额、磁盘还是其他存储故障，本版不把容量不足作为既定原因。

- 新 `persistence.js` 使用按内容 SHA-256 寻址的不可变题目/任务分片、64条引用页和一个提交指针。先写分片并读回验证，再切换指针，指针也读回确认；题目与任务游标在同一提交中生效。重复题目没有来源变化时重用原记录，不再写整个题库。保持原去重语义，选项/答案不同的记录全部保留供核对，跨章节来源、题目 ID 和解析合并不丢失。
- 旧版第一次成功写入时迁移：完整写入新结构、重新解码并比较全部数据，校验成功才发布新指针。随后再提交本次变化。迁移失败仍从旧结构读取，旧 `questionBankV1` **始终保留，不自动删除**。内部存储结构改变，导出的 `schema_version:1` JSON 不变。
- 自动响应采用双缓冲本地回执日志；只有确认上一回执已提交后才复用旧缓冲，不覆盖待提交响应。网络任务不会因存储失败被标记完成。Worker/浏览器重启后优先使用本地回执，无需旧页面仍在。
- 后台仍统一串行读改写，提交加 Web Lock 和持久化版本检查；拒绝陈旧快照、已完成任务回退、计数减少、题目/来源丢失及运行中计划替换。停止/暂停不深拷贝整个题库，题目索引、摘要和不变分片引用可以复用。
- Chrome Promise 拒绝与 callback `runtime.lastError` 均处理；15秒存储调用超时后阻止后续写入，等待原调用实际结束，避免迟到写入覆盖新提交。存储完全不可写时无法保证把故障标记也写入磁盘，但不确认任务成功；重启后按原持久化请求 ID 探测，无法确认则暂停，不自动重放。
- 本版申请 `unlimitedStorage`，避免默认 local 约10MiB额度限制题库分片加旧版备份；这不代表旧错误已证实由配额导致，也不能消除磁盘满或浏览器拒绝写入。为保护数据，不自动清理旧库或历史分片，磁盘使用量会增长；请定期导出 JSON。
- 「存储诊断」显示真实 `getBytesInUse` 使用量、题数、提交版本、最近成功提交时间、具体错误类别/阶段、待恢复情况及最近提交结果。错误只保存固定类别，不记录原始异常、响应头或认证信息。计划状态/进度来自同一持久化快照，显示当前与上一计划 ID；未完成计划不能被新计划静默替换。

遇到问题只需：保持扩展原位更新，打开弹窗点击「刷新统计」，记录「存储诊断」的错误类别、阶段、使用量、提交版本，以及计划状态/任务进度。不要提供 Cookie、Token 或完整网络日志。若有待恢复回执，先「恢复待提交回执」，成功后再「继续」；不要靠新建计划或清空存储消除错误。

## 登录会话和通信边界

没有在扩展后台直接请求 API，也没有新增 `api.aidhu.net` host permission。MV3 的 `webRequest` 不能读取响应体，本扩展不使用它。

现有公开前端（此前已下载的 `app.06f2eaf8.js`）明确配置：

```js
Vue.prototype.$api = O
O.get('/api/protected/app/manual/chapters', {params: {manual_id: t}})
// data 按 Object.keys(e.data) 转换为 {id: parseInt(t), name: e.data[t]}
```

真实压缩包变量名为 `a["default"]`（Vue）和 `O`（请求客户端）。三个题型 GET 请求传 `manual_id`、`chapter_id`；原站 `$api.get` 支持将其他配置原样传入 fetch。

扩展用 Chrome `scripting.executeScript` 在 MAIN 上下文调用 `document.querySelector('#app').__vue__.$api.get`。**认证由原站自己的现有客户端完成**，扩展不访问 `$store`、Token、Cookie、Authorization、请求头、请求体或登录存储；不复制客户端认证设置。若客户端不可用，不回退到提取令牌或构造认证头。请求在正常网页上下文遵守同源/CORS，使用原站认证逻辑，不关闭浏览器安全保护。

只生成 `https://api.aidhu.net` 的以下四个已知 GET 路径：

- `/api/protected/app/manual/chapters`：`manual_id`，成功响应 `{code:200,data:{"1":"章节名称"}}`。
- `/api/protected/app/manual/chapter/questions/one_choice`
- `/api/protected/app/manual/chapter/questions/multi_choice`
- `/api/protected/app/manual/chapter/questions/judge`

客户端 baseURL 必须精确为 `https://api.aidhu.net`；请求禁用重定向，检查最终 URL 和 HTTP 状态，失败暂停。状态观察只读取 status/url，不读取 headers。自动请求与原被动采集区分，防止同一响应保存两次或错误推进两项任务。

原被动观察器继续运行：MAIN 的 fetch/XHR 监听在 `document_start` 安装，通过同窗口、精确 origin、路径、字段及大小白名单向 ISOLATED 接收器发送筛选后的数据；后台再次校验扩展 ID、顶层文档及来源。自动响应由 Chrome scripting 返回经过投影的题目，后台再次过滤上下文后复用规范化和去重。

网页是非可信环境，来源校验不构成密码学上的服务器数据来源证明。页面不能通过普通 window 消息启动/继续自动任务、读取或导出本地库。自动开始和控制、导入导出只接受本扩展 popup.html；存储设置为 TRUSTED_CONTEXTS。

## 数据、去重、导入导出

三种题型保留 `question`、`question_type`、标准化 `options`/`answer`、清洗后的 `source`/`analysis`，并保留 `explanation`、解析变体、题目 ID。未知字段和原始响应不入库。判断题按原站的 1/0 正误映射，不猜测 A/B。

1.2.0 根据本次要求将扩展去重范围改为**跨章节**：题型、题干、选项、答案完全相同只保存一条，在 `contexts` 数组记录各手册/章节。旧库中按章节分别保存的重复记录，在下一次成功合并写入时自动归并。代表记录的 manual_id/chapter_id 和 SHA-256 record_id 保持 Python 标准格式。各章数量按 contexts 计算，所以各章之和可能大于全库唯一题数。

选项或答案不同分别保留并计为待核对冲突；同题不同来源/解析保留在 explanations。不静默覆盖冲突。Python 工具本身保持原来的章节级规则；它能导入此扩展 JSON，扩展的 contexts/source/analysis 为额外兼容字段，Python 工具不保证原样保留这些额外字段。

- 导出为 `schema_version:1`、`questions`、`report`；不包含内部队列、标签页 ID 或认证信息。
- 导入 JSON 自动合并、去重，兼容原 API data 数组、题目数组、Python/扩展导出及既有分组格式。UTF-8/BOM，最多 20 MB、单次 50000 条；导入不会推进自动任务。
- 仍可通过“仅离线记录”使用 1.1.0 的被动观察计划；自动计划运行/暂停时不能另建离线队列。暂停/停止计划不禁用用户正常练习的被动保存。

```bash
python3 tools/question_bank.py downloaded.json -o /tmp/normalized-bank.json
```

卸载扩展或清理浏览器数据会删除本地库；不会同步到 Google 账户。JSON 是备份，不提供自动清空。

6. 多轮结束自动停止并显示各轮新增。导出文件能下载并由 Python 导入，题库和暂停进度在浏览器重开后保留。
